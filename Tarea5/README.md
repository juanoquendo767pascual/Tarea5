## Contenido

- `DDL/01_modelo_fisico_postgresql.sql`: esquema de 12 tablas con claves y restricciones.
- `SQL/01_datos_demostracion_opcionales.sql`: datos totalmente ficticios para prueba.
- `SQL/02_consultas_dml_final.sql`: cinco consultas SELECT verificadas.
- `SQL/03_creacion_vistas_final.sql`: tres sentencias CREATE OR REPLACE VIEW verificadas.
- `SQL/04_consultas_sobre_vistas.sql`: tres SELECT sobre las vistas.
- `SQL/00_EJECUCION_COMPLETA_PG16_BD_VACIA.sql`: ejecuta todo en una BD de prueba vacia; no usar en produccion.
- `SQL/05_verificacion.sql`: inventario de tablas y vistas.
- `Informe/`: informe final en DOCX y PDF con codigo, justificaciones y ocho evidencias reales.
- `Evidencias/`: ocho capturas tomadas en db<>fiddle (PostgreSQL 16).
- `Diagramas/`: imagen y fuente del modelo fisico.
- `Video/`: guion individual y archivo para escribir el enlace de YouTube una vez grabado.
- `Borrador/`: version preliminar archivada; **la version final es la de SQL/ e Informe/**.

## Validacion

Las cinco consultas y las tres vistas fueron ejecutadas con exito en db<>fiddle PostgreSQL 16, con datos de demostracion exclusivamente ficticios (SELECT 10, 4, 5, 8, 4 y tres CREATE VIEW seguidos de SELECT 6, 4, 5). No se afirma que exista un servidor permanente ni datos reales de estudiantes.
